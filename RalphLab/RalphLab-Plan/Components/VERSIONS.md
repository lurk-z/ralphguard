# กติกาเวอร์ชันของ Component (V1 / V2 / ...)

ทุกบันทึกใน [COMPONENTS-INDEX](COMPONENTS-INDEX.md) เริ่มที่ **V1** เก็บโค้ดตามที่ใช้งานจริงเมื่อ 19 พ.ย. 2569 (commit `ddd97e1` บน `jay-sandbox`)

## เมื่อแก้ component

1. **ไม่เขียนทับ V1** ใน note เดิม โค้ด V1 ต้องอยู่ครบเพื่อย้อนกลับได้
2. เพิ่มหัวข้อ `## โค้ด V2` ใต้ `## โค้ด V1` ใส่โค้ดเต็มของไฟล์หลังแก้
3. เพิ่มแถวในตาราง `## ประวัติเวอร์ชัน`: รุ่น · วันที่ · สิ่งที่เปลี่ยน · commit
4. ใน `## ไฟล์ที่ต้องมี` และ `## การติดตั้ง` ใส่เฉพาะ **ที่เพิ่มหรือเปลี่ยนใน V2** ว่าไฟล์ไหนสร้างใหม่ แพ็กเกจไหนติดตั้งเพิ่ม (ถ้าไม่มีให้เขียนว่า "ไม่เปลี่ยนจาก V1")
5. ถ้าเปลี่ยนว่าใช้หน้าไหน ให้แก้ตาราง `## ใช้งานหน้าไหน` และ front matter (`pages`)
6. เปลี่ยน `version: V1` ใน front matter เป็น `V2` และอัปเดตคอลัมน์ "รุ่น" ใน [COMPONENTS-INDEX](COMPONENTS-INDEX.md)

ขนาดและหน้าที่ใช้ตรวจใหม่ได้ด้วย `npm run inventory` ใน `frontend` แล้วดูที่หน้า `/test_components`

````markdown
```
````
