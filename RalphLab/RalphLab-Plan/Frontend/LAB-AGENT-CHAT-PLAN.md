# Lab Agent Chat — แผนออกแบบ UI

> ร่าง UI แชตรุ่นแรก เก็บข้อเสนอคำถามแนะนำและรูปแบบเดิมไว้เป็นประวัติ · ข้อตกลงปัจจุบันดู [[AGENT-DEMO-SPEC]] และ [[CODEX-FE-MASTER]]

**สถานะ** · ฉบับร่างสำหรับ FE คนเดียว เริ่มจากต้นแบบ UI เมื่อเห็นว่าการเลือก Agent สลับประวัติ และลากปรับความกว้างใช้งานได้ดีแล้ว ค่อยยืนยันหน้าตาและเริ่มเชื่อมระบบจริง งานนี้มาก่อนหน้า Node และการต่อยอดสถานีทดลอง 3D

## 1. ร่างหน้าตาแชตให้เห็นก่อน

ใช้ภาพ Codex ที่ให้มาเป็นตัวอย่างเรื่องการจัดวาง เช่น ประวัติที่เปิดได้จากหัวแชต ช่องส่งข้อความอยู่ล่าง และมีเส้นขอบให้ลาก ใช้พื้นเข้มโทนเขียวอมเทาของ Ralph Lab โลโก้กระต่ายของโปรเจกต์ และสีเน้นของ Agent ในแถบชื่อหรือปุ่มที่เลือก พื้นหลังหน้าแชตว่างใช้โลโก้โปร่งเบา ๆ ส่วนเมื่อเริ่มคุยให้พื้นหลังเรียบเพื่อให้อ่านข้อความง่าย

```text
┌─────────────────────────┬─────────────────────────────────┐
│                         │ Ralph Lab          ประวัติ  ＋  × │
│         Lab 3D          │ [ภาพ] นักวิเคราะห์              │
│                         │ สูตรที่กำลังดู · V1              │
│      Agent ที่เลือก     ║                                 │
│                         ║                  ข้อความของคุณ  │
│                         ║ คำตอบของ Agent                   │
│                         ║ คัดลอก · เวลา                    │
│                         │                                 │
│                         │ [ถาม Agent…]   คำถาม  ไมค์  ส่ง │
└─────────────────────────┴─────────────────────────────────┘
                           ↑ เส้นแบ่งลากได้
```

| ส่วน | สิ่งที่ต้องเห็นและลองกดในต้นแบบ |
|---|---|
| หัวแชต | โลโก้ Ralph Lab ภาพครึ่งตัว ชื่อ บทบาท สูตรและเวอร์ชันที่กำลังดู ปุ่มประวัติ เริ่มบทสนทนาใหม่ และปิดแผง |
| ประวัติ | แสดงรายการบทสนทนาของ Agent ที่เลือก มีชื่อย่อและเวลา กดเปิดกลับมาอ่านได้ เริ่มแชตใหม่โดยเก็บบทสนทนาก่อนหน้า |
| ข้อความ | ข้อความผู้ใช้อยู่ขวา คำตอบ Agent อ่านเต็มพื้นที่ มีปุ่มคัดลอกและสถานะ `คัดลอกแล้ว` รองรับข้อความไทย รายการ และการขึ้นบรรทัด แสดง `กำลังคิด` ระหว่างรอ แล้วค่อยทยอยแสดงคำตอบ |
| ช่องส่ง | ปุ่มส่ง `Enter` เพื่อส่ง `Shift+Enter` เพื่อขึ้นบรรทัดใหม่ ปุ่มไมค์ถอดเสียงลงช่องพิมพ์ให้ตรวจและแก้ก่อนส่ง แสดงสถานะฟังอยู่และแจ้งเมื่อใช้ไมค์ไม่ได้ |
| ป๊อปอัปคำถาม | ให้เป็นรายการคำถามแนะนำตามบทบาท กดแล้วเติมในช่องก่อนส่ง เช่น นักวิเคราะห์ `ผลของ V1 มี Endpoint ไหนที่ยังขาด?` และนักพัฒนาสูตร `สูตรนี้เปลี่ยนอะไรจากรุ่นก่อน?` |
| สถานะที่ต้องลอง | แชตว่าง กำลังตอบ มีคำตอบ เปิดประวัติ และส่งไม่สำเร็จพร้อมปุ่มลองใหม่ ถ้าเปิดลดการเคลื่อนไหวให้แสดงคำตอบเต็มได้ทันที |

ความหมายของ **ป๊อปอัปคำถาม** ในร่างนี้คือ *คำถามแนะนำให้ผู้ใช้กดเลือก* ส่วนคำถามที่ Agent ต้องถามกลับเพื่อขอข้อมูลเพิ่ม ให้ลองแสดงเป็นข้อความในแชตก่อน แล้วค่อยตัดสินใจจาก UI ว่าต้องมีปุ่มตัวเลือกเพิ่มไหม

## 2. ทำขอบลากและการเลือก Agent ให้ผ่านก่อนต่อ AI

1. **แบ่งพื้นที่ Lab ซ้าย / แชตขวา** ให้เป็นสองคอลัมน์ใน `LabRoomExplorer` เปิดแชตแล้วคอลัมน์ Lab หดตามพื้นที่จริง ปิดแชตแล้ว Lab กลับมาเต็มพื้นที่
2. **ลากขอบซ้ายของแผงเพื่อปรับความกว้าง** ให้เส้นขอบเห็นชัดตอนชี้หรือโฟกัส รองรับการปรับด้วยปุ่มลูกศรและจำความกว้างล่าสุด ลองค่าเริ่มต้นราว 400 px แล้วปรับจากร่างบนจอเดโม โดยจำกัดให้ทั้งแชตและห้องยังใช้งานได้
3. **ให้ห้องขยับตามกรอบ** เก็บ Canvas 3D ตัวเดิม ให้ขนาด viewport และการจัดกล้องอิงพื้นที่จริงที่เหลือ เมื่อเปิด ปิด หรือลากขอบ ตรวจว่า Agent ยังเห็นและคลิกได้ ฉากได้สัดส่วน กล้องไม่รีเซ็ต และการลากขอบไม่ไปหมุนมุมห้อง
4. **คลิก Agent ตัวไหนเปิดห้องแชตของตัวนั้น** ต่อจากจุดคลิกและตามกล้องที่มีอยู่ ใช้แผงเดิมสลับชื่อ รูป สูตรและประวัติตาม `agentId` เลือกข้ามบทบาทได้ทันที ลองสลับอย่างน้อยสองตัวขณะกำลังแสดงคำตอบเพื่อจับปัญหาข้อความข้ามห้อง

## 3. เตรียมภาพ Agent ครึ่งตัว

ต้นทางที่ผู้ใช้ระบุคือ `docs/ralph-lab/character-sheets/uniform-turnarounds/18k` ใช้ภาพมุม `front` ตัดจากศีรษะถึงช่วงเอว เก็บทรงผม ใบหน้า คอเสื้อและเสื้อกาวน์ ตั้งขนาดตัวละครให้ใกล้กัน ลบฉากหลังให้มีความโปร่งใส แล้วส่งออก WebP ขนาดประมาณ 512 × 512 สำหรับใช้ในแชต หัวแชตใช้ภาพขนาดเล็ก ส่วนหน้าแชตว่างใช้ภาพครึ่งตัวให้เห็นรายละเอียด เก็บ 18K ไว้เป็นภาพต้นทาง

## 4. ดึงส่วนที่ใช้ซ้ำได้จากผู้ช่วย AI เดิม

| จุดในโปรเจกต์                                                       | แผนที่เสนอ                                                                                                                |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `frontend/src/components/assistant/VoiceAssistant.tsx`              | ใช้ตรรกะส่งข้อความ จัดการ request พิมพ์ด้วยเสียง และทยอยแสดงคำตอบเป็นฐาน สร้างหน้าตาแชต Lab ขึ้นใหม่ให้ใช้ร่วมกันทุกบทบาท |
| `frontend/src/components/three/skincare-lab/agents/AgentFollow.tsx` | จุดเลือก Agent ที่ใช้ตามกล้องอยู่แล้ว ส่ง role ที่คลิกผ่าน Canvas ไปให้แผงแชต                                             |
| `frontend/src/components/three/skincare-lab/LabRoomExplorer.tsx`    | เป็นจุดประกอบ Lab แผงแชต และสถานี คุมว่าตัวไหนถูกเลือก ประวัติไหนเปิดอยู่ และพื้นที่ของแต่ละคอลัมน์                       |
| `frontend/src/app/(dashboard)/assess/page.tsx`                      | ส่งข้อมูลโครงการและสูตรที่เลือกให้ Lab ตอนเชื่อมจริง แล้วเอา UI ผู้ช่วยเดิมออกจาก Assessment หลังแชต Lab ผ่านการทดสอบ     |

- **เก็บประวัติแยกตามโครงการ → Agent → บทสนทนา** เริ่มด้วยที่เก็บฝั่งเบราว์เซอร์แบบเดียวกับที่ผู้ช่วยเดิมใช้ และให้ข้อความตอบกลับผูกกับห้องที่ส่งแม้สลับตัวระหว่างรอ แยกพื้นที่ประวัติเก่าของ Assessment ออกจากพื้นที่ใหม่ การย้ายประวัติเก่าไปยัง Agent ต้องตัดสินใจเพิ่มเติม
- **เชื่อมข้อมูลจริงทีละเส้นทาง** ส่งบทบาท โครงการและเวอร์ชันสูตรที่กำลังดูไปกับคำถาม แล้วตรวจขอบเขตที่ `/api/chat/` รองรับในปัจจุบัน การส่งบริบทจาก FE อย่างเดียวไม่ได้ยืนยันว่า backend รองรับทุกบทบาทหรือทำงานแทน Agent ได้ ให้ลองถามจาก Agent หนึ่งตัวด้วยสูตรจริงก่อนขยาย
- **ทยอยแสดงข้อความบน FE** ผู้ช่วยเดิมอ่านคำตอบ JSON เมื่อรับครบ แล้วค่อยแสดงเป็นช่วง ๆ ใช้วิธีนี้กับ MVP ได้ ส่วนการส่งคำตอบทีละชิ้นจากเซิร์ฟเวอร์ไว้พิจารณาหลัง MVP

## 5. ลำดับลงมือสำหรับ MVP

1. **ร่าง UI ด้วยข้อมูลตัวอย่าง** ทำหน้าว่าง หน้าประวัติ หน้าคุย และป๊อปอัปคำถาม ดูบนจอเดโมก่อนเลือกหน้าตาจริง
2. **ยืนยันว่าลากแผงข้าง Lab ได้** เปิดจาก Agent ในฉาก สลับตัว และทดสอบกล้องกับแผงสถานีขณะปรับพื้นที่
3. **ใส่ภาพครึ่งตัวและทำปุ่มหลักให้ครบ** ส่ง คัดลอก ไมค์ คำถามแนะนำ ประวัติ และแอนิเมชันแสดงคำตอบ
4. **เชื่อมผู้ช่วยเดิมเข้ากับ Lab** เริ่มจากคำถามหนึ่งชุดที่อ้างถึงสูตรจริง แล้วตรวจการแยกประวัติ การสลับตัวระหว่างรอ และสถานะเมื่อส่งล้มเหลว
5. **ไปต่อที่ร่าง Node เมื่อแชตผ่าน** ตอนปรับ Assessment ให้เอาผู้ช่วยออกแล้วทดสอบว่าหน้าประเมินยังทำงาน ส่วนการสั่ง Agent ให้เดิน ส่งหลอด หรือทำงานเต็มกระบวนการให้เชื่อมในรอบทำ Lab 3D

**ถือว่าพร้อมสำหรับ MVP** เมื่อคลิก Agent คนไหนก็เปิดแชตของคนนั้นได้ ส่งและอ่านคำตอบได้ ดูประวัติย้อนหลังได้ ข้อความตอบกลับไม่ข้ามห้อง ลากขอบแล้ว Lab ยังเห็นและใช้งานได้ และ Assessment ยังประเมินสูตรได้หลังย้าย UI ผู้ช่วยออก
