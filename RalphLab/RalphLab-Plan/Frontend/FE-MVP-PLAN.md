# Ralph Lab — แผน FE สำหรับงานแข่ง

> ร่างลำดับ FE รุ่นแรก เก็บไว้ดูที่มาของ Assessment และงานหลัง MVP แผนส่งมอบของสมาชิกคนที่ 2 อยู่ที่ [[MEMBER-02-FE-DELIVERY]] ส่วน [[AGENT-DEMO-SPEC]] และ [[CODEX-FE-MASTER]] อธิบายต้นแบบกับวิธีใช้ชุดโค้ดที่เตรียมไว้

> **สถานะ: ร่าง ยังไม่สรุป** · ทำ FE คนเดียว · ขั้นต่อไปคือร่าง UI แชต Agent ให้เห็นภาพ แล้วค่อยยืนยันหน้าตา การกดใช้งาน และขอบเขตที่จะลงมือทำ

ลำดับที่เสนอคือ **ร่างและทำ UI แชต Agent → ร่างหน้า Node → ลองสลับหน้าด้วยสูตรเดียวกัน → ปรับ Assessment → เชื่อมสถานีและการส่งตัวอย่างใน Lab 3D → ทดสอบเดโมครบหนึ่งรอบ** เริ่มใช้ห้องที่เตรียมไว้เพื่อทดสอบการเปิดแชตจากตัวละครและการแบ่งพื้นที่ ส่วนงานสถานีและผลทดลองทำต่อหลังเห็น UI ชัดเจนแล้ว

## 1. เริ่มจาก UI แชต Agent

ร่างแผงแชตด้านขวาให้มีประวัติของแต่ละ Agent ภาพครึ่งตัว ช่องพิมพ์ ปุ่มไมค์ ส่ง คัดลอก และคำถามแนะนำ ลองจับขอบลากแล้วให้ห้อง 3D ปรับกรอบตาม จากนั้นค่อยนำตรรกะจากผู้ช่วย AI เดิมมาเชื่อมกับแผงใหม่ [แผน Lab Agent Chat](LAB-AGENT-CHAT-PLAN.md)

## 2. ร่างหน้า Node

จุดแรกที่ควรวาดคือ **ต้นไม้สูตร + แผงรายละเอียดของสูตรที่เลือก** ลองใช้ข้อมูลตัวอย่างให้ครบทั้งสูตรต้นทาง สูตรที่แตกแขนง และสูตรที่ยังรอผล เพื่อดูว่าอ่านรู้เรื่องจากหน้าจอเดียวหรือเปล่า

```text
โครงการทดลอง                  [Assessment] [Lab 3D] [Workflow]

         V1                    รายละเอียดสูตรที่เลือก: V2-A
          │                    มาจาก: V1
     ┌────┴────┐               เปลี่ยนอะไร / เพราะอะไร
   V2-A       V2-B             ส่วนผสมและสัดส่วน
   มีผลแล้ว    รอผล              ผลตาม Endpoint / ข้อมูลที่ยังขาด
                               [เปรียบเทียบกับ V1]
```

- **บนการ์ด** ลองแสดงชื่อสูตร เวอร์ชัน สถานะ และสิ่งที่เปลี่ยนแบบสั้น ๆ เพื่อให้รู้ว่าแต่ละแขนงทดลองอะไร
- **เมื่อคลิกการ์ด** ลองแสดงปัญหาที่พบ สิ่งที่ Agent เสนอ สิ่งที่เปลี่ยนจริง ส่วนผสมและสัดส่วน ผลที่มี และสิ่งที่ยังต้องตรวจ ถ้ามีข้อมูลผู้สร้างสูตรให้แสดงประกอบ
- **เมื่อเทียบสูตร** เริ่มจากเทียบกับสูตรต้นทางเป็นค่าเริ่มต้น แล้วค่อยดูจากร่างว่าควรให้เลือกเทียบสองแขนงใน MVP ด้วยไหม เรียงผลตาม Endpoint เดียวกัน และแสดง `ยังไม่มีผล` ให้ชัด
- **ขอบเขตการใช้งาน** ผู้ใช้และ AI เปิดอ่านประวัติสูตรได้ การสร้างหรือปรับสูตรเกิดจากงานใน Lab ส่วน Node แสดงผลแบบอ่านอย่างเดียว โดยไม่มีคำสั่งแก้สูตร ลบ หรือรันการประเมิน
- **ยังต้องลองใน UI** ตำแหน่งแผงรายละเอียด วิธีเลือกสูตรที่จะเทียบ และคำที่ใช้แสดงสถานะ รวมถึงข้อมูลขั้นต่ำที่ต้องมีบนการ์ด

**พร้อมไปขั้นต่อไปเมื่อ** มองแผนผังแล้วรู้ว่า V2-A กับ V2-B มาจากสูตรไหน กดดูเหตุผลของการเปลี่ยนได้ และแยกสูตรที่มีผลแล้วออกจากสูตรที่ยังรอผลได้ทันที สองแขนงในร่าง UI ใช้ข้อมูลตัวอย่างได้ ระหว่างทำจริงให้เช็กว่าระบบส่งความสัมพันธ์ของสูตรมาให้แสดงได้แค่ไหน

## 3. ลองสลับสามหน้าด้วยสูตรเดียวกัน

ในร่าง UI ให้ลองเลือก `V2-A` ใน Workflow แล้วสลับไป Lab 3D และ Assessment ภายใต้โครงการเดิม มีชื่อสูตรและเวอร์ชันให้เห็นในแต่ละหน้า ลองสลับกลับมาเช็กว่าผู้ใช้ยังรู้ว่ากำลังดูสูตรไหนและผลชุดไหน จุดนี้จะช่วยกำหนดข้อมูลที่ FE ต้องรับร่วมกัน ได้แก่ โครงการ สูตร รุ่นต้นทาง และผลราย Endpoint เมื่อมีข้อมูล

**พร้อมไปขั้นต่อไปเมื่อ** อธิบายได้ว่าแต่ละหน้ารับข้อมูลอะไร แสดงอะไร และเมื่อสลับหน้าแล้วควรเลือกสูตรไหนอยู่

## 4. ปรับ Assessment ก่อนลงงานสถานี 3D

- ใช้กล่องสูตรเดิมเป็นฐาน ให้เห็นชื่อสูตร ส่วนผสมและสัดส่วนชัดเจน
- ปรับหน้าตาแถบประเมินและการแสดงผล โดยใช้กระบวนการประเมินเดิม
- เอา UI ผู้ช่วย AI ออกจากหน้านี้ แล้วลองประเมินสูตรหนึ่งครั้งให้เห็นว่าผลยังแสดงครบ

**เสร็จสำหรับ MVP เมื่อ** เปิดสูตร ดูสัดส่วน เริ่มประเมิน และอ่านผลจากหน้า Assessment ได้ครบ

## 5. กลับมาทำ Lab 3D จากห้องที่เตรียมไว้

เริ่มด้วยห้องและ Agent ที่มีอยู่ แล้วทำให้ใช้ได้ **หนึ่งเส้นทางครบก่อน** เช่น เลือกนักวิเคราะห์ → เปิดแชต → เห็นสูตรที่กำลังทำ → กดดูผลจากถาด → เลือกเก็บหรือทิ้ง → ย้อนดูสูตรและผลจากหลอดที่เก็บ

- **แชต** ใช้แผงที่ทำไว้จากขั้นแรก ลองเชื่อมคำสั่งในแชตกับงานจริงหนึ่งงานให้ครบก่อนเพิ่มคำสั่งเฉพาะบทบาท
- **สถานี** แสดงผลจากถาด 4 Endpoint แยกกัน ได้แก่ ระคายเคืองผิว ระคายเคืองตา แพ้สัมผัส และพิษเฉียบพลัน ถ้าถาดไหนยังไม่มีผลให้ขึ้นสถานะรอผล
- **ตัวอย่าง** หลังดูผลให้เลือกเก็บหรือทิ้งเป็นรายหลอด ถ้าเก็บ ให้คลิกหลอดในตู้เย็นแล้วดูสูตรเวอร์ชันเดิมและผลของหลอดนั้นได้ ถ้าทิ้ง ให้หลอดออกจากฉากและไม่ขึ้นในรายการหลอดที่เก็บ
- **การเคลื่อนไหว** ใช้การเดิน ส่งตัวอย่าง และทำงานที่สถานีประกอบงานที่เกิดในระบบ เริ่มจากช่วงส่งงานที่ใช้ในเดโมก่อน การเปลี่ยนหน้าตาโมเดลตามผลอยู่หลัง MVP

**เสร็จสำหรับ MVP เมื่อ** เปิด Agent ได้โดยไม่ต้องเริ่มจากลำดับตายตัว ดูผลจากถาด และเปิดผลเดิมจากหลอดที่เก็บได้ โดยข้อมูลสูตรตรงกับที่เห็นใน Workflow

## 6. เช็กว่าเดโม MVP จบแล้ว

- [ ] เปิดโครงการเดียวกันผ่าน Assessment, Lab 3D และ Workflow แล้วตามสูตรเวอร์ชันเดียวกันได้
- [ ] ทดลองเส้นทางจริงอย่างน้อยหนึ่งรอบตั้งแต่ V1 ไปถึงสูตรที่ปรับแล้ว และ Workflow แสดงความสัมพันธ์กับสูตรต้นทางได้
- [ ] เปิด Agent ดูผลตามถาด แล้วเก็บหรือทิ้งหลอดได้ ลองเปิดหลอดที่เก็บกลับมาดูข้อมูลอีกครั้ง
- [ ] สูตรที่ยังรอผลแสดงสถานะชัด และข้อมูลตัวอย่างที่ใช้ร่าง UI ระบุว่าเป็นตัวอย่าง

ถ้าต้องลดขอบเขต ให้จบเส้นทางจริง **V1 → V2** ก่อน แล้วเพิ่มแขนงที่สองและหน้าสลับเทียบตามร่าง UI งานหลัง MVP คือปรับ Responsive ให้ครบ ปรับ Login ปรับ Landing ให้ใช้โมเดลล่าสุดและโหลดไว และเพิ่มภาพการเปลี่ยนแปลงบนโมเดลตามผลประเมิน
