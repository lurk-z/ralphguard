# แผนทดสอบการส่งงานในห้องแล็บ

> บันทึกเดโม D01 รุ่นเดินตามบท ใช้ตรวจการเดินและขวด · ข้อตกลงปัจจุบันดู [[AGENT-DEMO-SPEC]] และ [[CODEX-FE-MASTER]]

เปิด `/lab-room?demoChat=1` เพื่อดูโครงการจำลองหนึ่งโครงการตั้งแต่รับโจทย์จนถึงการตัดสินใจหลัง V2 ข้อมูลรุ่นสูตร ผลรายด้าน และข้อความในโหมดนี้เป็นข้อมูลที่เขียนขึ้นเพื่อทดสอบ UI

## ลำดับที่ทำ

1. เอาป้ายชื่อซ้ำเหนือคำตอบออก ชื่อและรูปในหัวแชตยังใช้สลับเจ้าหน้าที่ได้
2. สร้างโจทย์สูตรทำความสะอาดหนึ่งโจทย์ เก็บส่วนผสม สัดส่วน เหตุผล ผลสี่ด้าน และความไม่แน่นอนแยกตามรุ่น
3. ให้แถวในลำดับงานระบุผู้ส่ง ผู้รับ สิ่งที่ส่งและเหตุผล ใช้แถวเดียวกันเลือกคนเดินและเขียนใบงาน เปลี่ยนสถานะเป็นส่งถึงเมื่อเดินถึงผู้รับ
4. ให้เจ้าหน้าที่รับโจทย์ ส่งข้อเสนอ ส่งขวด V1 ส่งผล และแจกงานแก้ไขตามปัญหาที่พบ รอบแก้ไขให้นักวิเคราะห์นำผลไปหานักวิจัย นักวิจัยส่งข้อเสนอให้นักพัฒนาสูตร แล้วส่งขวด V2 ไปตรวจซ้ำ
5. เปิดใบงานจากเจ้าหน้าที่หรือขวด ดูรุ่นที่เกี่ยวข้องและย้อนเทียบ V1 กับ V2 ได้เมื่อมีผลทั้งสองรุ่น ผู้เชี่ยวชาญโมเดลในเดโมคือหน้าที่เสริมของ Analyst
6. จบรอบที่สองเมื่อผลพิษเฉียบพลันยังอยู่นอกขอบเขต ให้ผู้ใช้ตัดสินใจเรื่องหลักฐานถัดไป เปิดหน้าใหม่เพื่อเริ่มฉายเดโมตั้งแต่ต้น

## เกณฑ์ตรวจรับ

- คลิกเจ้าหน้าที่คนใดก็ได้ ตรวจผู้ส่ง ผู้รับ และใบงานล่าสุดของคนนั้นได้ระหว่างชมเดโม
- คลิกขวดตอนสร้างหรือส่งตัวอย่างแล้วเห็นสัดส่วนของรุ่นนั้น ผลของรอบที่ยังไปไม่ถึงแสดงเป็นรอผล
- V1 คงสัดส่วนเดิมหลังสร้าง V2 สัดส่วนแต่ละรุ่นรวม 100% และเทียบผลทั้งสี่ด้านได้
- ตรวจเส้นทางสำหรับผลเกินเกณฑ์ สูตรมีสารที่ห้าม หลักฐานไม่พอ และผลนอกขอบเขต ครบทั้งสี่กรณี
- แชตเดโมใช้ข้อมูลใบงานปัจจุบัน ประวัติเดโมแยกจากแชตโครงการจริง และไม่มีการส่งตัวเลขจำลองเข้า Assessment
