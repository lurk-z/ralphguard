# RalphGuard — Use Cases สำหรับทดสอบระบบ

เอกสารนี้รวมตัวอย่างสูตร/สารสำหรับทดสอบให้เห็นผลแต่ละด้านชัดเจน, คำแนะนำการถ่ายรูปฉลากให้ OCR อ่านดีที่สุด, ชุดคำสั่งผู้ช่วย AI และ use case ของ Node Graph — ใช้ประกอบการนำเสนอ/สาธิต

## 1. Use Case สาร/ผลิตภัณฑ์ (แต่ละตัวเด่นคนละ endpoint)

> สร้างสูตรตามนี้แล้วกด **▶ Run ประเมิน** ระบบจะเติมน้ำ (Water/Aqua) เป็นเบสให้ครบ 100% อัตโนมัติ

### ผลิตภัณฑ์ A — โฟมล้างหน้าเข้มข้น → เด่น **ระคายเคืองตา (Eye)**
สารลดแรงตึงผิวเข้มข้น + กรด เป็นสูตรที่ระคายเคืองดวงตาสูง

| สาร | SMILES | % |
|---|---|---|
| Sodium Lauryl Sulfate | `CCCCCCCCCCCCOS(=O)(=O)[O-].[Na+]` | 15 |
| Cocamidopropyl Betaine | `CCCCCCCCCCCC(=O)NCCC[N+](C)(C)CC([O-])=O` | 8 |
| Citric Acid | `OC(=O)CC(O)(CC(=O)O)C(=O)O` | 2 |

**คาดหวัง:** ระคายเคืองตา = สูง · ระคายเคืองผิว = กลาง · อื่นๆ = ต่ำ

---

### ผลิตภัณฑ์ B — โทนเนอร์ผลัดผิว AHA → เด่น **ระคายเคืองผิว (Skin)**
แอลกอฮอล์สูง + กรดผลัดผิวเข้มข้น

| สาร | SMILES | % |
|---|---|---|
| Ethanol | `CCO` | 40 |
| Glycolic Acid | `OCC(=O)O` | 10 |
| Salicylic Acid | `O=C(O)c1ccccc1O` | 2 |

**คาดหวัง:** ระคายเคืองผิว = สูง/รุนแรง · ระคายเคืองตา = กลาง · อื่นๆ = ต่ำ–กลาง

---

### ผลิตภัณฑ์ C — บอดี้มิสต์น้ำหอม → เด่น **แพ้ผิวหนัง (Sensitization)**
สารก่อภูมิแพ้ในน้ำหอมหลายตัว

| สาร | SMILES | % |
|---|---|---|
| Ethanol | `CCO` | 55 |
| Cinnamaldehyde | `O=C/C=C/c1ccccc1` | 1.5 |
| Eugenol | `C=CCc1ccc(O)c(OC)c1` | 1 |
| Limonene | `CC(=C)C1CCC(C)=CC1` | 2 |

**คาดหวัง:** แพ้ผิวหนัง = สูง · ระคายเคืองผิว = กลาง · อื่นๆ = ต่ำ

---

### ผลิตภัณฑ์ D — น้ำยาฆ่าเชื้อ/สารทำความสะอาดเข้มข้น → เด่น **พิษเฉียบพลัน (Acute)**
มีสารที่มีพิษเฉียบพลันชัดเจน

| สาร | SMILES | % |
|---|---|---|
| Phenol | `Oc1ccccc1` | 5 |
| Formaldehyde | `C=O` | 1 |
| Ethanol | `CCO` | 30 |

**คาดหวัง:** พิษเฉียบพลัน = สูง · ระคายเคืองผิว = สูง · อื่นๆ = กลาง

---

### สูตรควบคุม (Control) — สูตรอ่อนโยน → **ทุกด้านต่ำ**
ใช้ยืนยันว่าระบบไม่ตีความสารอ่อนโยนว่าเสี่ยง

| สาร | SMILES | % |
|---|---|---|
| Glycerin | `OCC(O)CO` | 5 |
| Niacinamide | `O=C(N)c1cccnc1` | 3 |
| Panthenol | `OCC(C)(C)C(O)C(=O)NCCCO` | 2 |

**คาดหวัง:** ทุก endpoint = ต่ำ · ความเชื่อมั่น = สูง (in-domain)

## 2. OCR — รูปแบบรูปที่ระบบจับได้ดีที่สุด

ระบบอ่านเฉพาะ **บล็อกรายการส่วนผสม (Ingredients / Ingredienti)** แล้วจับคู่ชื่อ INCI → SMILES

**✅ ควรทำ**
- ถ่าย **เฉพาะส่วนที่เป็นรายการส่วนผสม** (ครอปให้ชิด ไม่เอาโลโก้/ราคา/ที่อยู่)
- ฉลากเป็น **ภาษาอังกฤษ (INCI)** — ระบบออกแบบสำหรับ INCI มาตรฐาน
- ตัวอักษร **ดำบนพื้นสว่าง**, คมชัด, ความละเอียดสูง (≥ 1000 px ด้านกว้าง)
- ถ่าย **ตรง แบนราบ** ขนานกับฉลาก, แสงสม่ำเสมอ ไม่มีเงา/แสงสะท้อน (glare)
- รองรับ JPG, PNG, WebP, TIFF · ไฟล์ ≤ 10 MB

**❌ ควรเลี่ยง**
- ถ่ายเอียง/โค้งตามหลอด/ขวด (ตัวอักษรบิดเบี้ยว)
- แสงสะท้อนวาบบนพลาสติกเงา
- ถ่ายด้านหน้าผลิตภัณฑ์ (ไม่มีรายการส่วนผสม)
- ฉลากที่มีแต่ข้อความโฆษณา/สรรพคุณ (ไม่มีคำว่า Ingredients)

**เกิดอะไรขึ้นเบื้องหลัง:** ตัด block Ingredients → split คอมมา → จับทั้งชื่อ INCI (ไม่ฉีกครึ่งคำ) → คลังในระบบก่อน แล้วค่อย PubChem → กรองคำกำกวม/ขยะ

## 4. Node Graph — Use Cases

โหมด **Nodes** ทำให้ "อัลกอริทึมที่ชัดเจน" ของ QSAR มองเห็นเป็นภาพ (ตาม OECD Principle 2)

### UC-1: สร้างสูตรแบบกราฟ
กด **+ เพิ่ม node สาร** → เลือกสารจากคลัง → ลากเส้นจากทุก node สาร → **node ผลการประเมิน** → กด run ใน node ผล

### UC-2: ใช้ "ตัวปรับ" (Modifier) ลดฤทธิ์
เลือก **🧩 + ตัวปรับ** (สารจริงจากคลัง เช่น Glycerin/Panthenol) แทรกระหว่าง สาร → ผล เพื่อดูว่าคะแนนความเสี่ยงลดลงเท่าไหร่ — สาธิตแนวคิด "ปรับสูตรให้ปลอดภัยขึ้น"

### UC-3: เทียบหลายสูตรพร้อมกัน
กด **🎯 เพิ่ม node ผลการประเมิน** หลายตัว → ต่อสารคนละกลุ่มไปคนละ node ผล → เทียบคะแนนของแต่ละสูตรข้างกัน

### UC-4: บันทึกกราฟเป็นสูตร
สร้างกราฟเสร็จ → กด **💾 บันทึกเป็นสูตร** → กราฟถูกแปลงเป็นสูตรใหม่ในลิสต์ (น้ำเติมให้ครบ 100% อัตโนมัติ) นำไปประเมิน/แก้ต่อได้

### UC-5: ลบเส้นเชื่อม
คลิกที่เส้นเชื่อม → กด **✕ ลบเส้นเชื่อม** เพื่อเอาสารออกจากการคำนวณโดยไม่ลบ node
