# Ralph Lab · เอกสารส่งต่อสำหรับ Claude

Ralph Lab เป็นแนวทางที่เจ้าของโครงการวางไว้เพื่อต่อยอด RalphGuard สำหรับทีมพัฒนาสูตรเครื่องสำอางและแล็บวิจัยขนาดเล็ก หน่วยหลักของระบบคือ **โครงการทดลอง** ทีมใช้การคัดกรองด้วย QSAR เป็นส่วนหนึ่งของการสร้างตัวอย่าง ประเมิน ทบทวน และปรับสูตรเป็นรุ่นถัดไป

โครงการเตรียมนำไปแข่งขัน **Sea x OpenAI Regional Codex Hackathon Thailand** วันที่ **21 พฤศจิกายน 2569** ทีมมี **4 คน** กำหนดการประกาศให้เริ่มพัฒนา 10:00 น. และส่งงาน 17:00 น. ตามเวลาไทย [รายละเอียดงานและกติกา](HACKATHON.md)

## ลำดับอ่าน

1. [แนวคิด Ralph Lab](RALPH_LAB_CONCEPT.md) — ข้อความและตัวอย่างจากเจ้าของโครงการ ครอบคลุมโครงการทดลอง บทบาท ใบงาน สูตรแต่ละรุ่น และห้องแล็บ 3D
2. [บริบทและระบบ RalphGuard](RALPHGUARD_CONTEXT.md) — บริบทตั้งต้นจากไฟล์ `RalphGuard_Ralph_Lab_Context_and_Prompt.txt` และสิ่งที่ตรวจพบจากโค้ด รวมถึงที่มาของผลคัดกรองและข้อจำกัด
3. [Sea x OpenAI Regional Codex Hackathon Thailand](HACKATHON.md) — กำหนดการ เงื่อนไขผู้จัด และรายละเอียดจากข้อความตอบรับที่ทีมได้รับ
4. [สารบัญเอกสารทั้งหมด](../README.md) — คู่มือฟีเจอร์ เอกสารวิทยาศาสตร์ การตั้งระบบ และบันทึกของ RalphGuard

## บริบทสำหรับการสนทนาต่อ

ใช้แนวคิดของเจ้าของโครงการใน `RALPH_LAB_CONCEPT.md` เป็นจุดอ้างอิงของ Ralph Lab รายละเอียดของ MVP การแบ่งงาน วิธีเชื่อมระบบ และแนวทางที่จะใช้ยื่นในงานยังอยู่ระหว่างการหารือของทีม เมื่ออ้างถึงความสามารถปัจจุบัน ให้ยึดเส้นทางโค้ดที่ลิงก์ใน `RALPHGUARD_CONTEXT.md` และระบุสถานะการตรวจสอบตามจริง

ชื่อโครงการในแชตเดิมเขียนว่า `raplh lab` เอกสารชุดนี้ใช้ชื่อ **Ralph Lab** ให้ตรงกันทั้งชุด
